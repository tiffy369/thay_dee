# THAY DEE CLOTHING (ຮ້ານເທ່ດີ ແຟຊັ່ນ / เท่ดี เสื้อผ้าแฟชั่น) 👕✨
เว็บแอปพลิเคชันสำหรับขายสินค้าออนไลน์ (เสื้อผ้าแฟชั่น) พร้อมระบบตะกร้าสินค้า กรอกที่อยู่จัดส่ง ชำระเงินด้วย **BCEL OnePay QR Code** (ธนาคารการค้าต่างประเทศลาว / BCEL One) รองรับสกุลเงิน **กีบ (₭ / LAK)** กำหนดหมวดหมู่สินค้าได้เอง และสลับภาษาลาวพร้อมฟอนต์ **Phetsarath OT**

---

## 🌟 จุดเด่นและฟังก์ชันการทำงาน

### 1. 🇱🇦 รองรับ 2 ภาษา & สลับเป็นฟอนต์ Phetsarath OT อัตโนมัติ
- มีปุ่มสลับภาษาที่แถบเมนูด้านบน: **🇱🇦 ລາວ | 🇹🇭 ไทย**
- เมื่อเลือกภาษาลาว:
  - ฟอนต์ทั้งหน้าเว็บจะปรับเปลี่ยนเป็น **`Phetsarath OT`** (พร้อมสำรองด้วย `Noto Sans Lao` จาก Google Fonts) ทำให้แสดงผลสระและพยัญชนะภาษาลาวได้อย่างประณีต สวยงาม ชัดเจน และสระไม่ซ้อนทับกันบนทุกอุปกรณ์ (มือถือ Android, iPhone, Windows, Mac)
  - ข้อความบนหน้าเว็บทั้งหมดจะสลับเป็นภาษาลาว เช่น *ຄົ້ນຫາເສື້ອຜ້າ, ເພີ່ມໃສ່ກະຕ່າ, ກະຕ່າສິນຄ້າ, ສັ່ງຊື້ ແລະ ຊຳລະເງິນ, ທີ່ຢູ່ຈັດສົ່ງ, ຫຼັງບ້ານຮ້ານຄ້າ*
  - จดจำภาษาที่เลือกลงในเครื่องอัตโนมัติ เปิดเว็บครั้งถัดไปยังคงเป็นภาษาเดิม

### 2. ₭ สกุลเงินกีบลาว (Lao Kip - LAK)
- แสดงราคาสินค้า, ยอดรวมในตะกร้า, ค่าจัดส่ง, และยอดชำระเงินทั้งหมดเป็นหน่วย **กีบ (₭)** เช่น `₭120,000`, `₭250,000`
- คำนวณโปรโมชั่นส่งฟรีอัตโนมัติ เช่น ช้อปครบ `₭400,000` จัดส่งฟรี (หรือกำหนดได้เองในหน้าตั้งค่า)

### 3. 🏷️ ระบบกำหนดและจัดการหมวดหมู่สินค้าได้เอง (Custom Categories)
- เจ้าของร้านสามารถเข้าเมนู **"หลังบ้านร้านค้า" -> แท็บ "หมวดหมู่สินค้า (Categories)"** เพื่อ:
  - เพิ่มหมวดหมู่สินค้าใหม่ได้ตามต้องการ ระบุชื่อทั้งภาษาลาวและภาษาไทย
  - ลบหมวดหมู่ที่ไม่ต้องการได้ตลอดเวลา
  - หมวดหมู่ที่สร้างจะไปปรากฏบน **แถบตัวกรองหน้าแรก (Category Pills)** และใน **เมนูเลือกหมวดหมู่ตอนลงขายสินค้าใหม่** ทันทีโดยอัตโนมัติ

### 4. 📸 อัปโหลดรูปสินค้าได้โดยตรงจากเครื่อง (Direct Image Upload)
- ตอนเพิ่มสินค้าใหม่ในหน้าหลังบ้าน สามารถกดปุ่ม **"เลือกรูปภาพจากเครื่อง / ຖ່າຍຮູບ"** ได้ทันที (รองรับทั้งไฟล์ในคอมพิวเตอร์ และกล้อง/คลังภาพในมือถือ)
- เลือกได้หลายรูปพร้อมกัน มีแถบพรีวิวแสดงรูปภาพ
- มีระบบย่อขนาดภาพอัตโนมัติ (Smart Downscaling) เพื่อให้โหลดได้เร็ว และไม่เปลืองพื้นที่จัดเก็บ

### 5. 💳 ระบบชำระเงิน BCEL OnePay QR Code & แนบสลิปโอนเงิน
- แสดงบัตรชำระเงิน **BCEL OnePay** สีแดงเอกลักษณ์ พร้อมคำอธิบาย 2 ภาษา (*ສະແກນເພື່ອຊຳລະເງິນ / สแกนเพื่อชำระเงิน*)
- แสดงยอดเงินที่ต้องชำระ, เลขที่บัญชี BCEL (ເລກບັນຊີ), และชื่อบัญชีร้านค้า (ຊື່ບັນຊີ) พร้อมปุ่ม **"คัดลอกเลขบัญชี"** ในคลิกเดียว
- รองรับทั้งการสร้าง QR Code อัตโนมัติ หรือ **อัปโหลดรูปภาพ BCEL OnePay QR Code จริงของร้านที่บันทึกจากแอป BCEL One**
- มีปุ่มดาวน์โหลดรูป QR Code เก็บไว้ในเครื่องเพื่อนำไปเปิดสแกนในแอป BCEL One
- มีนาฬิกานับเวลาถอยหลังการชำระเงิน 15 นาที
- ช่องอัปโหลดรูปสลิปหลักฐานการโอนเงิน (Image Slip Upload) พร้อมแสดงรูปพรีวิวทันที
- หน้าสรุปคำสั่งซื้อสำเร็จ พร้อมปุ่มสั่งพิมพ์ใบสั่งซื้อ / ใบเสร็จรับเงิน (Printable Receipt)

### 6. 🛒 ระบบตะกร้าสินค้า (Slide-over Cart Drawer / "ปักตะกร้า")
- ปุ่มปักตะกร้าพร้อม Badge นับจำนวนสินค้าอัตโนมัติ
- แถบตะกร้าสไลด์ด้านข้าง (Slide-over Drawer)
- ปรับเพิ่ม/ลดจำนวน หรือลบรายการได้ทันที
- แถบแสดงยอดซื้อคงเหลือเพื่อรับสิทธิ์ส่งฟรีแบบไดนามิก

### 7. 📦 ระบบกรอกที่อยู่จัดส่ง (Shipping Address & Checkout)
- ฟอร์มกรอกชื่อ-นามสกุล, เบอร์โทรศัพท์, ที่อยู่จัดส่ง, ตำบล/แขวง, อำเภอ/เมือง, จังหวัด/แขวง, รหัสไปรษณีย์ และหมายเหตุถึงคนส่งของ
- บันทึกที่อยู่ล่าสุดไว้ในเครื่องอัตโนมัติ ไม่ต้องกรอกซ้ำในการสั่งซื้อครั้งต่อไป

### 8. ⚙️ ระบบหลังบ้านสำหรับเจ้าของร้าน (Admin Management)
- เข้าได้จากปุ่ม **"หลังบ้านร้านค้า"** บนเมนูด้านบน
- **แท็บรายการคำสั่งซื้อ (Orders)**: ดูออเดอร์ทั้งหมด ตรวจสอบที่อยู่ลูกค้า ยอดเงิน ดูรูปสลิปโอนเงิน BCEL One ขนาดเต็ม และเปลี่ยนสถานะออเดอร์ (รอตรวจสอบ -> ชำระเงินแล้ว -> กำลังจัดเตรียม -> จัดส่งแล้ว -> สำเร็จ)
- **แท็บจัดการสินค้า (Products)**: เพิ่มสินค้าใหม่ เลือกลงรูปตรงจากเครื่อง กำหนดราคา ไซส์ สี สต็อก
- **แท็บหมวดหมู่สินค้า (Categories)**: เพิ่มหรือลบหมวดหมู่สินค้าได้เองอย่างอิสระ
- **แท็บตั้งค่าร้านค้า (Settings)**: แก้ไขชื่อร้านค้า, สโลแกน, เลขบัญชี BCEL, ชื่อบัญชีร้าน, อัปโหลดภาพ QR Code ของร้าน, ค่าส่ง และเกณฑ์ส่งฟรี

## 💡 คำแนะนำสำหรับการใช้งานจริง

1. **การตั้งค่าบัญชี BCEL One ของคุณ**:
   - กดปุ่ม **"หลังบ้านร้านค้า"** ที่มุมขวาบนของหน้าเว็บ
   - ไปที่แท็บ **"ตั้งค่าร้านค้า & BCEL One"**
   - ใส่เลขบัญชี BCEL และชื่อบัญชีร้านของคุณ
   - หากคุณมีรูปภาพ OnePay QR Code ที่บันทึกมาจากแอป BCEL One ให้กดเลือกไฟล์ที่ **"ภาพ BCEL OnePay QR Code ของร้านค้า"**
   - กดปุ่ม **"บันทึกการตั้งค่า"** ระบบจะนำภาพ QR Code จริงและข้อมูลบัญชีของคุณไปแสดงให้ลูกค้าสแกนจ่ายทันที!

2. **การเพิ่มหมวดหมู่สินค้าของคุณเอง**:
   - กดปุ่ม **"หลังบ้านร้านค้า"** -> ไปที่แท็บ **"หมวดหมู่สินค้า (Categories)"**
   - พิมพ์ชื่อหมวดหมู่ (เช่น กางเกงขาสั้น, เสื้อกันหนาว, เครื่องหนัง) แล้วกด **"เพิ่มหมวดหมู่"**
   - หมวดหมู่นี้จะพร้อมใช้งานทันทีทั้งที่หน้าแรกและตอนเพิ่มสินค้าใหม่!

3. **การเพิ่มสินค้าใหม่ด้วยรูปจากเครื่อง**:
   - กดปุ่ม **"หลังบ้านร้านค้า"** -> ไปที่แท็บ **"จัดการสินค้า (Products)"**
   - คลิกที่กล่อง **"คลิกเพื่อเลือกรูปภาพจากเครื่อง หรือถ่ายรูป"**
   - สามารถเลือกรูปได้หลายรูปพร้อมกัน กรอกชื่อสินค้า ราคากีบ ไซส์ สี แล้วกด **"บันทึกและเพิ่มสินค้า"**
